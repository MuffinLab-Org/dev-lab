# MUFFIN Lab 公共笔记导航

> **团队规则**：
> 1. 按“技术主题”分类建立文件夹。
> 2. 每篇 `.md` 文件第一行写 `作者：@github-id`，以及日期。
> 3. 文件名统一使用小写连字符（如 `cpp-env-setup.md`）。
> 4. 新增笔记后，请同步更新本导航表。

## 如何新增笔记？
1. 在 `docs/notes/` 目录下新建文件（点击 GitHub 右上角的 `Add file` -> `Create new file`）。
2. 首行写上 `作者：@你的名字`，以及日期。
3. 回到本 `README.md`，在上面的表格中增加一行。
4. （如果是本地开发）提交并发起 PR；如果是网页端，直接 Commit。
