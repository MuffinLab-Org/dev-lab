# MUFFIN Lab - Dev-Lab

> **MUFFIN** === **M**ulti-disciplinary **U**nified **F**ramework **F**or **I**nterdisciplinary **N**etworking（多学科交叉与互联统一框架）。

这里是 MUFFIN Lab 的开发实验室与协作沙盒区域。

## 目录结构
- `docs/`：团队文档、接口规范与 MUFFIN 架构探讨
- `playground/`：成员个人练习沙盒（允许随意折腾、试错）
- `projects/`：团队联合开发的实战项目

## 协作规范
1. **随意探索**：现阶段允许直接在 `main` 分支上修改和提交代码（网页端或本地 Git 均可）。
2. **建个自己的地盘**：请先在 `playground/` 目录下建一个以你名字命名的文件夹，随便放点你的代码或笔记。
3. **Commit 信息**：提交时，尽量用一句话说清楚你干了啥（例如：`add intro file for ZhangSan`）。
4.**修改注意事项**：请不要随意破坏他人代码或其他成果，在进行本地git操作时，留意不要修改其他人的代码和文件。
